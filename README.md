# Гороскоп на месяц и год — как читать и проверять прогноз

Когда сравниваете гороскопы, запишите период и то, для кого он составлен. Общий текст по знаку, годовой обзор и личные транзиты используют разные исходные данные. Сравнивать их удобно по одному вопросу.

| Формат | Что уточнить перед чтением | Что записать |
|---|---|---|
| Гороскоп на месяц по знаку | Какой знак и какой календарный месяц использован | Период, тему и конкретную формулировку |
| Гороскоп на год | Обзор по знакам или по месяцам | К какому месяцу относится тезис |
| Личные транзиты | Какой момент рождения и какие положения взяты | Планета, аспект, дата и допуск |

## Пример записи

Представим фразу «в декабре станет легче выделять время для учёбы». Запишите заранее, что именно сможете заметить, например число занятий по неделям. Отдельно запишите планы, которые уже были. В конце месяца сравните исходную фразу с наблюдениями и отметьте, какой вывод остаётся неопределённым.
